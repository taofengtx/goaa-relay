Install Steps

1

Download the Installer

Click the button above to download, or run in a terminal:

wget https://api.goaa.ai/downloads/aika-node_1.0.4.deb Click to Copy
2

Run the Installer

Run in a terminal (requires sudo password):

sudo dpkg -i aika-node_1.0.4.deb Click to Copy
3

Restart the Device

After the install completes, restart; the AiKa node starts automatically:

sudo reboot Click to Copy
