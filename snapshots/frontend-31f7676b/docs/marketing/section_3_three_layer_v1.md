## 🎨 Framer 操作 step-by-step

由於 Framer 是視覺化編輯, 師兄按以下步驟重做:

### Step 1: 在 Hero 下方加新 Section

1. Framer 編輯模式
2. 在 Hero section 下方 (或刪除 Radison services section 的位置) 加新 section
3. 高度: 至少 1200px (3 個大卡片佔位)
4. 背景: 漸層 `#0a0e1a → #0d1830`
5. Padding: 100px 上下, 40px 左右

### Step 2: 加 Section Header

1. 加 Heading: "One platform. Three layers. Real outcomes."
   - 字體: 56px, Inter Bold, 白色
2. 加 Text: "一個平台 · 三層架構 · 真實成果"
   - 字體: 24px, 灰 #94a3b8
3. 加 Text: 副標題 (約 800px 寬, 居中)
   - 字體: 18px, 淡灰 #cbd5e1

### Step 3: 加 3 欄 Grid

1. 加 Grid container (或用 Flex)
2. 3 欄 (responsive: 手機 1 欄, 平板 2 欄)
3. Gap: 24px
4. 最大寬: 1400px, 居中

### Step 4: 每個卡片 (重複 3 次)

每個卡片:
1. 加 Container, 圓角 16px, 邊框 1px
2. Padding: 40px
3. Hover effect: borderColor 變亮 + translateY -4px

**卡片內元素**:
- 大 Emoji 圖示 (48px)
- 標題 (28px, 對應顏色)
- 副標題中文 (16px, 灰)
- Tagline (16px, 白, 粗)
- Tags (小 chips, flex-wrap)
- Tiers 表格
- CTA 按鈕

### Step 5: 底部 trust signal

加 Text: "Built in public · Open governance"
字體: 14px, 暗灰 #64748b, 居中

### Step 6: 響應式 (重要)

Framer 響應式設定:
- Desktop: 3 欄
- Tablet (768-1024): 2 欄, 第 3 個換行
- Mobile (<768): 1 欄, 卡片全寬

### Step 7: Publish + 驗證

按 Publish → 1-2 分鐘 → 真實 visit goaa.ai

## 💡 給 future Claude / 設計師的真心話

如果你接手 Three-Layer Architecture 改造:

1. **三層順序不可改** — Client → Provider → Worker (戰略憲法第 3 章固定)
2. **顏色不可換** — 藍 / 綠 / 橙對應 (跟 portal Dashboard 一致)
3. **Runtime Truth 嚴守** — Workers Live: 5 是真實, 不要寫 500 / 5000
4. **AiKa Box 露出** — 在 Provider 卡片提一下, 不要藏起來
5. **三個 CTA 對應 3 個觀眾** — Client / Provider / Worker, 不是 1 個按鈕

師兄今天 (2026-05-16) 凌晨指出主頁要做大公司級, Three-Layer 是核心差異化。
