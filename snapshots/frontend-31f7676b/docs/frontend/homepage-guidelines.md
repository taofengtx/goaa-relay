# Portal Homepage Guidelines

## Design Principles

- **Clarity**: Clear hierarchy and navigation
- **Responsiveness**: Mobile-first design
- **Accessibility**: WCAG 2.1 AA compliance
- **Performance**: <2s load time

## Layout Structure

```
Header
├─ Logo & Brand
├─ Navigation Menu
└─ User Profile

Hero Section
├─ Headline
├─ Value Proposition
└─ CTA Button

Features Section
├─ Feature Cards (3-4 items)
└─ Icon + Description

Social Proof
├─ User Testimonials
├─ Usage Statistics
└─ Trust Badges

Footer
├─ Links
├─ Legal
└─ Contact
```

## Content Guidelines

### Headlines
- Clear and benefit-focused
- 6-10 words max
- Action-oriented language

### Copy
- Use active voice
- Avoid jargon
- Keep paragraphs short (2-3 sentences)

### Visuals
- High-quality images (2MB max)
- Consistent color scheme
- Clear iconography

## Technical Requirements

### Performance
- Lighthouse score: 90+
- FCP: <1.5s
- LCP: <2.5s

### Browser Support
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

### Security
- HTTPS only
- CSP headers
- CORS validation
