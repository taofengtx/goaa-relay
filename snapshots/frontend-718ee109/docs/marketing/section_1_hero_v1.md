### Framer 操作步驟

#### Step 1: 修改 Hero 主標題

1. 在 Framer 找 Hero section (通常是第一個)
2. 點現有主標題 (像 "GOAA is an AI-powered life and asset intelligence system")
3. 替換為:
   ```
   The AI Labor Platform
   for Complex Lives
   ```
4. **字體**: 大 (60-80px), 粗 (Inter Bold / Display)
5. **顏色**: 純白 (#ffffff) 或 漸層白 → 藍 (#60a5fa)
6. **行距**: 緊湊 (1.1)

#### Step 2: 修改副標題

1. 點現有副標題
2. 替換為英文版:
   ```
   GOAA.AI turns complex human needs into work that AI understands, 
   Providers serve, Workers execute, and Skills sustain.
   ```
3. **字體**: 中 (18-22px), 一般 (Inter Regular)
4. **顏色**: 中灰 (#94a3b8)
5. **行距**: 1.6

#### Step 3: 加中文副標題 (在英文下方)

1. 新增 text element
2. 內容:
   ```
   GOAA.AI 把人的複雜需求, 轉化為:
   AI 可理解 · Provider 可服務 · Worker 可執行 · Skill 可沉澱
   ```
3. **字體**: 中 (16-20px)
4. **顏色**: 淡灰 (#cbd5e1)
5. **間距**: 上方 marginTop 16px

#### Step 4: 修改 CTA 按鈕 (從 1 個改 3 個)

如果 Framer 原 Hero 只有 1 個 CTA (像 "Get Started"), 改成 3 個橫排:

**按鈕 1: Try GOAA Free →**
- **連結**: `https://portal.goaa.ai` (跳到 dashboard)
- **顏色**: 藍 (#60a5fa) 主色, 白字
- **大小**: 中

**按鈕 2: Join Worker Network →**
- **連結**: 暫時 `mailto:tao@goaa.ai?subject=Worker Network Application` 或 Google Form
- **顏色**: 透明背景 + 橙邊框 (#fb923c), 橙字
- **大小**: 中

**按鈕 3: Investors →**
- **連結**: 暫時 `mailto:tao@goaa.ai?subject=GOAA Investor Inquiry` 或 Calendly link
- **顏色**: 透明背景 + 灰邊框 (#94a3b8), 灰字
- **大小**: 中

**3 按鈕排列**: 橫排 (flex-row), gap: 16px, marginTop: 32px

#### Step 5: 加底部小字 (Runtime Truth 暗示)

1. 在 CTA 下方加 text:
   ```
   Live workers · Real tasks · No mock data
   ```
2. **字體**: 小 (12px), 細
3. **顏色**: 暗灰 (#64748b)
4. **間距**: 上方 marginTop 24px

#### Step 6: 動畫 (可選, 大公司主頁標配)

如果 Framer 支援動畫:
- **主標題**: typing animation (3 秒打完)
- **副標題**: fade-in 0.5 秒 delay
- **CTA 按鈕**: fade-up 0.8 秒 delay
- **德牧 Logo**: 呼吸動畫 (scale 1.0 → 1.05, 3 秒 cycle, infinite)

## 💡 給 future Claude / 設計師的真心話

如果你接手 Hero 改造:

1. **一句話定義是法律** — 「AI 可理解 / Provider 可服務 / Worker 可執行 / Skill 可沉澱」不能改
2. **3 個 CTA 是戰略** — 用戶 / Worker / 投資人並重
3. **Runtime Truth 暗示** — 「No mock data」小字必須在
4. **雙語並行** — GOAA 服務全球華人, 不要只英文
5. **不要堆功能** — Hero 是門面, 簡潔比塞滿好
