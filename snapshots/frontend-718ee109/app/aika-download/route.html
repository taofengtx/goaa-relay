Install in Three Steps

About 5 minutes total; restart after installing and you are ready

01
Download the .deb Package
Click the "Linux (Ubuntu)" button above to download, or use the command line:。
wget https://portal.goaa.ai/downloads/aika-node_1.0.0.deb
02
Run the Install Command
Open a terminal and run the install command. The installer configures all dependencies and services automatically.
sudo dpkg -i aika-node_1.0.0.deb
03
Restart the System
Restart after installing; the system auto-logs in, creates an "AiKa Workspace" icon on the desktop, and opens the goaa.ai login page.
sudo reboot
● Automatically opens portal.goaa.ai/agent-login after restart
