## 🎯 為什麼 Use Case 重要

**抽象的「AI 勞動力平台」用戶聽不懂**, 必須用真實場景:
- 投資人看 Use Case → 評估 TAM (target market size)
- 用戶看 Use Case → 「這就是我!」共鳴
- Provider 看 Use Case → 「我能服務這類客戶」

**大公司主頁標配** (Stripe / Vercel 都有), GOAA 不能缺。

## 🎴 Use Case 1: Global Family (跨國家庭)

### 主圖示
🌏 (或自定義 SVG: 地球 + 家庭剪影)

### 標題
**EN**: `The Global Family`
**CN**: `跨國家庭`

### 場景 (Persona)
**EN**:
```
Sarah, 42, software engineer in San Francisco
- US W-2 salary $250K + RSU vesting
- Investment property in Vancouver
- Parents in Taipei (aging, healthcare planning needed)
- 2 kids: 8 and 11 (529 plan + dual-citizenship considerations)
- Just started taking care of her father's diabetes management remotely
```

**CN**:
```
Sarah, 42 歲, 矽谷軟體工程師
- 美國 W-2 年薪 $250K + RSU 股票分紅
- 溫哥華投資房產
- 台北父母 (年邁, 需要醫療規劃)
- 兩個孩子 8 歲 11 歲 (529 教育金 + 雙重國籍考量)
- 最近開始遠距協助父親糖尿病管理
```

### 痛點 (Pain)
**EN**:
```
Her CPA understands US tax. Her Taiwan accountant understands Taiwan tax.
But who connects them? Who tracks her father's medication when she's 6,000 miles away? 
Who reviews her RSU vesting impact on her Vancouver property strategy?

She has 7 advisors, 4 timezones, and no overarching plan.
```

**CN**:
```
她的美國 CPA 懂美國稅. 她台灣會計師懂台灣稅.
但誰把他們連起來? 當她遠在 6000 英里外, 誰幫忙追蹤父親的用藥?
誰評估她 RSU 對溫哥華房產策略的影響?

她有 7 個顧問, 4 個時區, 但沒有整體計畫.
```

### GOAA 怎麼解
**EN**:
```
✓ GOAA models complete family structure (US + Canada + Taiwan)
✓ AI generates 12-month executable path: tax / property / parent care / kids' education
✓ Connects Sarah to US CPA + Vancouver realtor + Taiwan medical Provider
✓ Workers handle docs, schedules, follow-ups across timezones
✓ Skills (e.g., "Medication Tracker") run on AiKa Box at home
```

**CN**:
```
✓ GOAA 模擬完整家庭結構 (美國 + 加拿大 + 台灣)
✓ AI 生成 12 個月可執行路徑: 稅務 / 房產 / 父母照護 / 子女教育
✓ 連接 Sarah 到美國 CPA + 溫哥華房仲 + 台灣醫療 Provider
✓ Worker 跨時區處理文件、行程、追蹤
✓ Skill (例如「藥物追蹤」) 在家裡的 AiKa Box 運行
```

### 結果 (Outcome)
**EN**: `Saves 12 hours/month. Cuts financial blind spots by 80%. Father's medication compliance: 97%.`
**CN**: `每月省 12 小時. 財務盲點減少 80%. 父親用藥依從性 97%.`

### 主色
藍 (#60a5fa, 對應 Client Layer)

## 🎴 Use Case 2: Tech Founder (技術創辦人)

### 主圖示
💡 (或自定義 SVG: 火箭 + 圖表)

### 標題
**EN**: `The Founder Pre-IPO`
**CN**: `IPO 前的創辦人`

### 場景 (Persona)
**EN**:
```
David, 38, Series C startup CEO
- $5M stock options vesting over 4 years
- $12M in vested but unsold shares (high tax exposure)
- Married, 1 kid (2 years), planning #2
- Considering moving family to Texas (tax + lifestyle)
- IPO planned within 18 months
```

**CN**:
```
David, 38 歲, C 輪新創 CEO
- $5M 股票期權 4 年分批 vesting
- $12M 已 vested 未售股份 (高稅務風險)
- 已婚, 1 個 2 歲小孩, 計畫生第二個
- 考慮舉家搬到德州 (稅務 + 生活)
- 18 個月內計畫 IPO
```

### 痛點
**EN**:
```
He has a wealth manager, but the manager doesn't know his cap table.
He has a tax attorney, but the attorney doesn't know his upcoming relocation.
He has a CFO, but the CFO doesn't think about his personal estate.

Three smart people. Zero coordinated strategy. Every decision is a $100K-$1M mistake risk.
```

**CN**:
```
他有財富顧問, 但顧問不知道他的 cap table.
他有稅務律師, 但律師不知道他即將搬家.
他有 CFO, 但 CFO 不管他的個人遺產規劃.

三個聰明人, 零協調策略. 每個決定都是 $100K-$1M 錯誤風險.
```

### GOAA 怎麼解
**EN**:
```
✓ GOAA models cap table + tax exposure + relocation impact + estate plan
✓ AI generates trade-offs: "Sell 30% RSU pre-IPO at $X tax cost vs hold"
✓ Connects to M&A lawyer + Texas relocation specialist + Estate attorney
✓ Workers run scenario analysis (Monte Carlo on outcomes)
✓ Skill: "IPO Tax Optimizer" runs ongoing simulations
```

**CN**:
```
✓ GOAA 模擬 cap table + 稅務風險 + 搬遷影響 + 遺產規劃
✓ AI 生成權衡方案: 「IPO 前賣 30% RSU 稅務成本 $X vs 繼續持有」
✓ 連接 M&A 律師 + 德州搬遷顧問 + 遺產律師
✓ Worker 跑場景分析 (蒙地卡羅模擬)
✓ Skill「IPO 稅務優化器」持續模擬
```

### 結果
**EN**: `Potential tax savings: $1.2M-$2.8M. Decision confidence: from 40% to 89%.`
**CN**: `潛在節稅 $1.2M-$2.8M. 決策信心: 從 40% 升至 89%.`

### 主色
紫 (#a78bfa, 高端 Client)

**CN**: `獨立 AI 開發者`

**EN**:
```
Alex, 28, full-stack developer in Singapore
- Day job: Senior engineer at Grab ($120K/year)
- Side: Built 3 small AI tools (none monetized successfully)
- Skilled in Python, LangChain, RAG, fine-tuning
- Wants passive income from AI but doesn't want to build a startup
```

**CN**:

```
- 副業: 做過 3 個小 AI 工具 (都沒賺錢)

- 想靠 AI 賺被動收入, 但不想創業
- 住一房一廳, 沒地方放 GPU 機房
```

### 痛點
**EN**:
```
Building AI tools is the easy part. Distribution, billing, customer support, marketing —

He needs a platform that handles the business side so he can focus on building.
```

**CN**:
```

「indie hacker」夢對大部分人來說只是迷因.

他需要一個平台處理商業面, 他只專注做開發.
```

### GOAA 怎麼解
**EN**:
```
✓ Alex joins Worker Network (free)
✓ Builds Skill "Tax Document AI" using Skill SDK
✓ GOAA handles: testing, security, billing, distribution, customer support, marketing
✓ Skill goes live on Marketplace at $4.99/month
✓ Alex earns 50% of revenue. GOAA handles the rest.
✓ Side income: $200/month → $2,000/month → $10,000/month (as user base grows)
```

**CN**:
```
✓ Alex 加入 Worker Network (免費)
✓ 用 Skill SDK 開發「稅務文件 AI」
✓ GOAA 處理: 測試、安全、計費、分發、客服、行銷
✓ Skill 以 $4.99/月 上架 Marketplace
✓ Alex 賺 50% 分潤, GOAA 處理其他.
✓ 副業收入: $200/月 → $2,000/月 → $10,000/月 (隨用戶成長)
```

**CN**: `Alex 的 3 個 Skill 每月帶來 $4,500 被動收入. 投入時間: 8 小時/月維護.`

## 💡 給 future Claude / 設計師的真心話

1. **Persona 真實感是關鍵** — 名字、年齡、地點都有具體性
2. **痛點要尖銳** — 「7 個顧問 4 個時區無整體計畫」這種句子打動讀者
3. **GOAA 解法用 ✓ 列點** — 視覺易讀
4. **Outcome 用數字** — 「$1.2M 節稅」比「節稅效果好」強 100 倍
5. **4 個 Use Case 對應 4 個觀眾** — 不要 4 個都是 Client
